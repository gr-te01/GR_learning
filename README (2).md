2.使用

本教程用我的理解来解析怎么实用的使用，非常通用，但这会造成可读性降低，对此抱歉....

&#x09;使用1（初步）：

&#x09;频繁的读取剪切板并不是一个软件应该有的好习惯，我建议你在设置中把读取剪切板改为禁止，写入改为每次使用时询问或者允许（在安卓14以上，这个方法可以生效，	安卓13以下，不保证）



&#x09;提防2（这就够了）：

&#x09;即使是现代的操作系统也无法保证你可以绝对安全，因此你可以翻翻"隐私设置项-隐私/隐匿模式"（例子）把对应的隐私模式启动，通常可以关闭摄像头，麦克风等隐私硬	件

&#x09;顺便一提，oppo这一点做得不错，oppo叫做**vip模式**。启动后物理断开摄像头麦克风定位，vivo叫做隐匿模式，不是硬件级别，可能有漏洞，且最近安卓有新型病毒可以	突破原子隐私系统的防护，一定要注意隐私和安全，此外，游龙工具箱（注：一款来自中国的防锁机软件，最近已经有了反病毒的影子）可以尝试，但只是尝试，而不是	当成一个绝对宝物（但确实做到的很棒）
